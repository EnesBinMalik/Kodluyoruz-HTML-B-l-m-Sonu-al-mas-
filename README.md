# Kodluyoruz HTML Bölüm Sonu Çalışması

![Kodluyoruz HTML Bölüm Sonu Çalışması — rozet](docs/rozet.svg)

> **Veri analizi · modelleme** — tasarım ve geliştirme: **Enes Öztürk**

---

Enes Öztürk HTML Eğitimi standartlarına tam uyumlu, semantik etiketlerle zenginleştirilmiş Lezzet Durağı web sitesi ve interaktif kod inceleme ortamı.

## Öne çıkanlar

- Veri temizleme ve hazırlık
- İstatistiksel özet ve görselleştirme
- Modelleme ve tahmin adımları
- Yönetici özeti ve rapor görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |
